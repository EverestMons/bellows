## Edit 2: 189/N5 — last-lens-line primary + closing fallback

**Before (lines 196–202):**
```python
closing_match = re.search(r'^\*\*Closing:\*\*\s*(.*)', dc_block, re.MULTILINE)
if not closing_match:
    print("WARN: Drafting Cycle block has no **Closing:** line (DRAFTING_CYCLE.md §3)")
else:
    closing_text = closing_match.group(1).lower()
    if 'fold' in closing_text and 'dry' not in closing_text:
        print("WARN: Drafting Cycle closing indicates fold as last event, not a dry lens pass (DRAFTING_CYCLE.md §2)")
```

**After (lines 196–221):**
```python
lens_line_re = re.compile(
    r'^-\s*(?:cold[\s-]+)?(?:weak[\s-]*spots|destruction|vulnerabilit|integration|acid)\b',
    re.IGNORECASE,
)
closing_pos = re.search(r'^\*\*Closing:\*\*', dc_block, re.MULTILINE)
search_region = dc_block[:closing_pos.start()] if closing_pos else dc_block
last_lens_line = None
for line in search_region.splitlines():
    if lens_line_re.match(line):
        last_lens_line = line

if last_lens_line is not None:
    ll_lower = last_lens_line.lower()
    has_fold = 'fold' in ll_lower
    has_dry = 'dry' in ll_lower
    if has_fold and not has_dry:
        print("WARN: Drafting Cycle closing indicates fold as last event, not a dry lens pass (DRAFTING_CYCLE.md §2)")
else:
    closing_match = re.search(r'^\*\*Closing:\*\*\s*(.*)', dc_block, re.MULTILINE)
    if not closing_match:
        print("WARN: Drafting Cycle block has no **Closing:** line (DRAFTING_CYCLE.md §3)")
    else:
        closing_text = closing_match.group(1).lower()
        if 'fold' in closing_text and 'dry' not in closing_text:
            print("WARN: Drafting Cycle closing indicates fold as last event, not a dry lens pass (DRAFTING_CYCLE.md §2)")
```

**Primary:** finds the last lens result line before `**Closing:**` using anchored regex (`^-\s*(?:cold[\s-]+)?(?:weak[\s-]*spots|destruction|vulnerabilit|integration|acid)\b`, case-insensitive — matches warm and cold-panel lens lines incl. hyphenated "Cold weak-spots"). Applies the SAFE rule (CB1): WARN iff the line contains a fold-family token AND does NOT contain `dry` anywhere. This prevents false fold-WARNs on real Walk-3 ACID lines like `→ dry. 11 folds cohere` where "folds" follows "dry".

**Fallback:** if no lens lines are parseable (legacy/degenerate blocks), falls back to the existing closing-line keyword check — preserves back-compat.

**WARN message unchanged:** `"Drafting Cycle closing indicates fold as last event, not a dry lens pass (DRAFTING_CYCLE.md §2)"` — keeps both `fold` and `dry lens pass` substrings (CB2).
