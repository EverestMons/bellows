## Context

Component 4 — the CAPSTONE — of the cycle-automation arc (proposal §11): the **self-driving walk loop** that replaces the CEO's per-walk "continue". Mechanism: run walk N (5 lenses, fold, **COMMIT**) → `cycle_check` → `CONTINUE` auto-runs walk N+1 · `BAR_MET` closes + emits the manifest · `ESCALATE` PAUSES for the CEO (resumable, one-word resume). This read-only diagnostic characterizes the loop, its non-fabrication substrate, and the doctrine amendment, and produces the Rule 27 Gap Assessment the amendment (a governance in-place §2 edit, like 2a) implements WITHOUT re-verification (T-7).

**The central tension this diagnostic must resolve:** auto-advancing walks in one pass is PRECISELY the fabrication the standing guards forbid ([[no-fabricated-drafting-cycle]] · [[drafting-cycle-one-pass-per-turn]]). The loop is safe ONLY because `cycle_check`'s asserts make each walk NON-FABRICABLE — and those asserts (#2 walk-register coherence, #3 fold_check baseline) return **N/A on a scratchpad draft with no committed register** (verified this session — every dogfood ran "asserts #2/#3 N/A"). So the loop's load-bearing prerequisite is the **committed per-walk substrate**, which §2.7/§3 ALREADY MANDATE but these scratchpad cycles have NOT practiced. Without the substrate, auto-advance = fabrication; with it, cycle_check verifies each walk and the CEO can leave the loop.

**Live proof-of-concept (this session's evidence):** 2a + component-3-diagnostic + component-3-executable each ran the loop MANUALLY — the CEO drove each walk ("walk"/"continue"/"go") and `cycle_check` was the per-walk gate (CONTINUE→continue, ESCALATE:yield-rising→a real CEO pause at 2a walk 4, BAR_MET→close). The capstone replaces the CEO-as-driver with auto-advance — but ONLY once the substrate the CEO was standing in for is in place.

**This is a READ-ONLY design diagnostic** (like diagnostic-472/478): reads the doctrine + cycle_check + the walk-register machinery, produces the design + gap table, changes no code/doctrine. The amendment it designs is a **T-6 §2 governance surface** and earns its own cold-panel consideration downstream.
