## Why this exists

A tool that writes a committed file when asked for its help text turns every reader of the tool surface into a writer. The census found it by accident; the next reader would find it the same way. The fix makes invoking a tool safe by construction and pins it for every tool the shop adds.

## What this does NOT do

- Snapshot the governance tree in t3 and t4 — the Planner writes registers there while plans run, so a snapshot would flake; the static checks guarantee no tool names a governance path absolutely, and none of the six writes there.
- Require `argparse` by text — `run_check.py`'s hand-made usage is safe and stays.
- Regenerate, move or edit the historical evidence files, or move the instruments out of `tools/`.
- Change what any census measures.
