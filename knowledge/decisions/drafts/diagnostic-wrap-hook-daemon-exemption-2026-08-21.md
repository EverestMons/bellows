**The two channels are NOT the same trigger — this is the correction that reframes the fix:**
- **Channel 1 (SessionStart injection) is not sentinel-gated at all.** `wrap_debt_hook.py` never reads `.wrap-in-progress`; it runs `wrap_check.py` unconditionally at every session start and injects the debt directive whenever the check exits nonzero. Since `wrap_check` asserts in-flight ritual DELTAS (uncommitted `Done/` plans, uncommitted verdicts) and check 3b requires a `Lessons-swept: <today>` baton line, a nonzero exit is the NORMAL state of a working day before its wrap. Exposure is structural and near-continuous, not "while a wrap is armed".
- **Channel 2 (Stop-lock capture) requires the sentinel** and is the damaging one: the worker cannot end its turn until **the CEO's wrap** verifies, so it acts on shared repos it was never scoped to.

**⚠️ The obvious detection mechanism does not work — do not author the fix around it.** `runner.py:207` passes `--append-system-prompt BELLOWS_AGENT_SYSTEM_PROMPT` ("You are executing as a Bellows-dispatched agent"), but **a hook never sees the system prompt**; its stdin payload carries session/cwd/event fields only. The candidate mechanism is an env var set on the spawn (`runner.py:216-221` currently passes no `env=` and merely inherits) and read by the hooks — but that premise is UNVERIFIED and is Q3 below. A cwd heuristic (`.bellows-worktrees/` in the path) is insufficient on its face: in-place dispatch runs with cwd set to the project root ([[governance-in-place-dispatch]]).

**⚠️ Scoping discovery that changes the DOWNSTREAM tier:** the entire enforcement layer — `~/.claude/eluvian/{wrap_check,wrap_arm_hook,wrap_stop_hook,wrap_debt_hook}.py`, `~/.claude/commands/wrap.md`, and the `~/.claude/settings.json` hook wiring — lives in **no git repository** (`git rev-parse` under `~/.claude` → "not a git repository"; a `find` across `Developer/GitHub` returns no versioned copy). An edit there has no diff, no revert, and no gate can see it. That makes the eventual executable **T2** (T-6 governance/enforcement surface + T-5 not-cleanly-revertible), and it is why Q7 exists.
