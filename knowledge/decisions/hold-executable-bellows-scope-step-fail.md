The helpers close #100074's open fork: the per-step reading copied the union's set build and match, and a fix to one copy would have missed the other.

## What this does NOT do

- It does not change the union rule, the allowlist, or which plans count as declared.
- It does not read step 1, an undeclared (legacy) plan, or a direct caller that passes no `warnings`.
- It does not change the ledger's schema or `lifecycle.py`: a failed step's one `scope_step` row is its `fail` row (P3).
- It does not classify by kind, extension or content: every file a later step commits that only an earlier step declared fails alike.
- It does not survive a return of cumulative diffs: were a later step's file list to carry an earlier step's files again, this FAIL would read them as the later step's own edits (P9's premise).
- It does not remove the WARN plumbing — `check()`'s `warnings` key, the table's WARN row, the ledger's `earlier-step-only:` reason — which no gate writes after it (open fork 2).
- It does not write the doctrine texts (the CEO's apply act at four sites, quoted in Post-close).
